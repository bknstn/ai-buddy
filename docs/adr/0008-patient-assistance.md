# ADR 0008: Make patience and practical care explicit

Date: 2026-10-03

Status: Accepted

## Context

A goal-oriented persona can overemphasize productivity and treat pauses or repeated questions as failures.

## Decision

Use patient, practical assistance that respects changed plans, uncertainty and the user’s freedom to choose. Ground help in available evidence; a clearer explanation, smaller plan or deliberate pause can be a useful outcome.

## Consequences

This is prompt guidance, not a behavioral guarantee. It grants no additional monitoring, notification or action permissions. Existing frozen sessions may need an intentional prompt refresh.
