# Hermes context

This file is a pointer for repository agents, not a record of a live Hermes installation. Read the [Hermes runtime module guide](../../runtimes/hermes/README.md) and [module context](../../runtimes/hermes/context/hermes.md) for its scope, upstream release policy and integration-specific constraints.

Hermes is separate from this repository and is not assumed to be installed on the current machine. The legacy integration set records v0.21.7 as its tested compatibility baseline; this is not a latest-version claim. Use operator-provided paths and inspect live state before any authorized host operation. Keep all installation details, credentials and operational evidence private.
